# 水墨 · Ink Wash

> 写意水墨在宣纸上展开动画：留白即空间，一笔即山、即浪、即手势、即一刀。
> 参考语法：上海美术电影制片厂《山水情》(1988)（留白空间、墨晕、古琴节奏）；
> 《卧虎藏龙》竹林打斗（失重感、动前静）。勿复制其角色、构图或音乐。

## 1. 本质与不是

一眼认出水墨的 3-5 个特征：
- 黑墨在暖色宣纸上，五色层次（焦浓重淡清）
- **没骨**画法：浓边即轮廓，不用西画式勾线
- 大部分画面是**留白**：水、天、雾、沉默
- **唯一红色**：朱砂印，最多一个故事小物件呼应
- 形态是**画出来的**，不是切出来的

不是水彩（没有彩色渲染），不是矢量加笔触纹理（没有平涂或封闭轮廓），不是书法片头。

## 2. 材质与渲染

- **宣纸**：程序生成，不用纹理图文件。暖色宣纸 (~`#F2ECDE`)、云斑、长纤维、纸浆点、缩小时渐隐的颗粒、轻微暗角。锚定在世界坐标。
- **墨**：笔触不透明度乘到纸上（不是叠加），五色：

| 色 | 不透明度 | 用途 |
|---|---|---|
| 焦 | ~.96 | 书法、最锐利的线、苔点 |
| 浓 | ~.82 | 轮廓、浓笔的暗边 |
| 重 | ~.60 | 副线、褶皱 |
| 淡 | ~.34 | 山体、衣袍与身体渲染 |
| 清 | ~.16 | 远山、面部、雾 |

- **笔触模型**：中心线 × 压力轮廓 × 宽度噪声 + 4–60 根**笔毫**，墨量沿笔触递减、长程噪声处断开。
- **浓淡笔**：一侧笔毫更深，笔触自带轮廓：这让身体、石头、浪读起来像墨，不是矢量。
- **两层**：湿层在合成器里晕染（噪声模糊、边缘色素堆积、颗粒化）；干层只有纤维抖动和纸面齿感。
- **团块**：柔边多边形、抖动边缘、渐变；绝非平涂。
- **山水**：山向下溶入雾带，近山有披麻皴和苔点；石头 = 轮廓 → 斧劈皴 → 阴影渲染 → 点苔。
- **水即留白**：用淡的干笔痕和开口墨环暗示流动。实水：宋代**平行波纹线**（近边密）或浅色体 + 几笔大浓笔勾面。
- **人物即写意**：一个淡色体块 + 两笔浓笔，焦墨线条勾四肢；五官最多 3–5 笔。

## 3. 色彩逻辑

- 只有墨，从低密度的冷灰到满密度的暖黑。世上没有别的色相。
- **一个朱砂** (~`#B02E22`)，给印和故事中最多一个小物件。小物件在远景中找到主角，可与印呼应。绝不要红渲染、红文字。
- 值承载深度：远 = 淡而柔，近 = 重而有纹理。画面太满时，减墨而不是加色。

## 4. 运镜语法

| 运镜 | 表达 | 可服务于 |
|---|---|---|
| 锁定画面于纸上 | 纸即舞台，东西被画进来 | 事物成形；读一行字；一个安静的决定 |
| 右→左平移（手卷） | 时间与距离是一幅画 | 旅程；历史；过程 |
| 垂直摇（挂轴） | 高度、层叠的阶段 | 四季；攀登；世代 |
| 横向跟随，留前方空间，慢视差 | 在世界中运动 | 旅行；追逐；通勤 |
| 高远广角，小人在空白中 | 渺小、孤独 | 寂寞；自然的尺度 |
| 低角度，深色团块高耸，慢推 + 震动 | 重量、威胁 | 障碍；风暴；压力 |
| 硬切到极端特写 | 流动中的断裂（此风格唯一允许的硬切） | 决定；冲击；记忆 |
| 推进墨晕或雾中 | 在状态间穿过 | 记忆；梦；季节转换 |
| 拉远到一个标记融入全画 | 局部原来在整体之中 | 总结；尺度反讽 |
| 回到之前的构图 | 韵脚显示变化了什么 | 余波；成长；前后对比 |

构图：60–80% 留白；暗色前景可沿画面底部掠过。转场用墨晕、手卷平移或雾；绝不通用溶解或擦除。

## 5. 运动质量

- **人物以 12 fps 步进**（on twos）；位置、镜头、晕染、涟漪和飞沫以 24 fps on ones 运动。
- **静态笔触 on twos**：每笔由其索引加种子，飞白断裂沿**归一化弧长** × 固定参考长度计算，飞白间隙不会每帧爬动。只允许宽度噪声的轻微"沸腾"。
- **画出来**：笔触按绘画顺序出现。
- **动前静**（决定性一笔作为事件时）：静止，最多慢推，然后让笔触在几帧内穿过画面。后果只在笔触完成后开始。
- 没有东西像矢量形那样补间：东西被画出来、晕开或溶入雾中。

## 6. 声音调色板

- **古琴为主**，不是钢琴和弦乐：古琴（开放弦与按弦、滑音、颤音、泛音、扫弦）、低沉洞箫、大鼓和定音鼓铺量、手鼓铺脚步、小锣铺印章。中国五声音阶。
- **画面驱动，不要循环**：无拍子的拨弦适合空灵、脉冲适合运动、滚奏适合体量；笔触可各自落在一声拨弦上。
- **沉默是字面意义的**：整条总线归零（音乐、环境、混响尾巴），短淡入淡出。沉默内最多一个声音（一滴、一声回响）。放在故事屏息的地方。
- **音效跟随材质**：墨滴（短"叮"+ 软湿撞击）、笔风（带笔毫颗粒的带通噪声，不是金属呼啸）、水上脚步（小溅）、飞沫（湿滴答）、印章（木质撞击 + 纸裂声）。

## 7. 原生技法（此媒介独有的招式）

- **一笔即一切。** 适合：一件产品从一条线诞生；一座城市从一条街长出来；一天从一只鸟开始。
- **空即是物。** 减墨见纸白。适合：墙上开门；人群让路；全家福中的缺席。
- **笔 = 手势 = 动作。** 笔序成为编舞。适合：舞者拼出一个字；签名；厨师刀工。
- **飞白。** 一笔快速干笔穿过画面，最强出于沉默。适合：冲刺终点；决定；彗星。
- **墨晕转场。** 下一场景在一个扩散的墨滴中生长，有暗色潮线。适合：记忆；季节；一个时代让位给下一个。
- **手卷。** 一幅长画从右向左平移，最后看到全貌。适合：历史；从田到手的供应链；一条街的一天。

## 8. 介质陷阱

- 干笔看起来像虚线 → 用长程噪声断裂 + 墨量沿笔触递减
- 平行半透明笔触让身体像管风琴 → 一个底色团块 + 两笔浓淡笔
- 大侧锋看起来像梳子 → 渐变团块 + 几笔低干燥度笔触
- 分干湿两层的笔触体丢失密度 → 干层给完整体 + 湿层给光晕
- 用字体轮廓裁剪书法会磕碰节点 → 字体只作为骨架
- 波浪内均匀排线变成铁丝网 → 沿面部用浓淡笔

## 9. 引擎映射（映射到 p5.brush / core.js）

| STYLE.md 概念 | 本项目实现 |
|---|---|
| 宣纸 | `paint()` 的 `fill` + `tex` 参数；纸色 `#F2ECDE` |
| 墨色五色 | `PAL` 中增加 `ink_jiao/ink_nong/ink_zhong/ink_dan/ink_qing` |
| 笔触（浓淡笔） | `inkLine()` + 自定义压力轮廓函数 |
| 湿层晕染 | `paint()` 的 `bleed` 参数 + `wash` |
| 留白 | 不画 = 纸色可见 |
| 朱砂 | `PAL.vermilion = '#B02E22'` |
| 12 fps 步进 | `onTwos(t)` |
| 沸腾 | `boilSeed()` + 宽度噪声 |
| 墨晕转场 | 自定义 `inkBloom()` 转场函数 |

## 10. 变化空间

每次影片由 agent 决定：结构、角色（或无）、山水、开场、结尾、运镜路径、节奏、红色的位置。

三种远离示范的结构：
1. **一字成篇**：一个大字的每一笔展开成一个主题小品
2. **挂轴四季**：从天到地的垂直摇镜，经过四个阶段
3. **两笔对话**：交替的笔触互相回应，直到在一团墨晕中相遇
