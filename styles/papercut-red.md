# 剪纸 · Red Paper-cut

> 中国窗花剪纸动起来：铰接红色裁切件在纸底上，剪刀痕即绘画、镂空即透光之处。
> 参考语法：陕西/蔚县民间窗花（锯齿、月牙、云纹、旋涡、折对称团花、阴阳剪法）；
> 1958–59 上海美术电影制片厂剪纸短片（关节人物、侧面表演、纸层视差）。
> 勿复制工作室角色或具名艺术家作品：所有图案由代码生成，片中不提参考来源。

## 1. 本质与不是

每个可见的东西都是**一张被剪刀裁过的纸**平放在另一张纸上。没有绘画、没有渐变阴影、没有描边：细节、体积和表情只来自**被裁掉的部分**。红纸是主角材质；底也是纸（白昼用浅纸、夜晚用深染纸）。人物是**铰接剪影**（头、躯干、上下肢在铆钉处钉住）以硬 12 fps 步进动画。

不是皮影：没有幕后透光、没有半透明染色皮、没有杆。这里纸是**正面打光且不透明**的；背光只留给最需要的那个时刻。不是平面矢量（没有描边、没有渐变），不是剪影片（每个形的内部都被裁过）。

## 2. 材质与渲染

- **纸纹**：每个部件内部用 `soft-light` 的中性灰纹理（染料斑驳、纤维、斑点），然后用 `destination-in` 恢复 alpha，使镂空保持镂空。
- **裁边**：每个轮廓是一条带轻微低频波浪的折线（手裁感），左上 1 px 亮边、右下暗边（裁面）。建筑和机器用直线段 + 波浪，不光滑。
- **纸厚**：每个部件在下层投紧致柔阴影；折叠纸叠层显示 2–6 条偏移暗边。
- **人物：红块 + 阴刻线。** 每个人物部件有一条**内嵌轮廓**（轮廓内几单位的细缝）：经典双轮廓，也分离红叠红的重叠（手臂叠在外套上）。
- **民间裁切词汇**：锯齿行（毛、草、瓦、流苏）、锯齿边、月牙（鳞片、绗缝）、旋涡（关节）、云纹、团花、梅花、铜钱、锥形缝。
- **没有浮岛。** 闭合环裁切会让中心从真纸上掉落。眼睛是上下两条月牙（留桥），加一个镂空瞳孔。
- 脸从不变形：表情是**可换脸片**（微笑、惊讶、恐惧、坚定、睡着）。
- **团花**设计为一个 45° 楔形 × D4 镜像 8 次；其他折法给 2×、4× 或 6×。交替阳剪（裁掉带、留红线）和阴剪（从红场裁出线）。折缝留淡折痕：保留它们，忠于工艺。
- **光**：正面打光场景直接用纸。夜间：`frame × lightmap` + 暖池，然后**发光**的背光件（光 × 纸透射 via `multiply`；镂空全亮），两级光晕和可选光线。保持光晕足够低让中心图案仍可读。
- **投影图案**：部件的镂空遮罩压到地面上用 `lighter` 相加；在角色上由层 alpha 遮罩。

## 3. 色彩逻辑

- **中国红** (~`#d2201f`，范围 `#c8102e`–`#d7261e`) 是主角材质。深度和角色用**差一步的纸色**显示，不是阴影：近件一步亮、远件一步暗、对手或重物一步深。
- **底和主角必须是不同纸族。** 如果背景和主角都是红，轮廓就不再跳出。夜间所有背景层是一种深染族，只有故事关键的件是红；白昼浅纸底 + 红和浅红层。
- **金箔**是只留到一个迟来时刻的点缀（太阳、标题、铜币）；不是第二主色。
- 底的族：靛蓝夜纸（远层浅蓝、近层深蓝）；暖宣纸白昼 + 浅红远丘；玉绿或黑纸用于非节庆故事。

## 4. 运镜语法

| 运镜 | 表达 | 可服务于 |
|---|---|---|
| 极近景跟踪剪刀尖 | 制作；对手艺的关注 | 工作开始；精确行为；签名 |
| 正面平面锁定 | 剪影作为徽章 | 标题；宣言；全家福 |
| 慢速平移穿越纸层（视差） | 展开的世界 | 村庄、路线、时间线 |
| 低广角，一个形从地面层站起 | 尺度、威胁 | 风暴；对手；截止日到来 |
| 俯视桌面 | 工艺即情节 | 折叠、裁切、组装、分拣 |
| 推到一个亮件，拉到多个 | 一个行为扩散 | 影响力；网络亮起 |
| 翻页 / 剥纸 | 时间或地方改变 | 昼到夜；前后；章节 |
| 拉到房间里的一个物件 | 影片是一个人做的东西 | 记忆；礼物；传统 |
| 绕团花中心旋转 | 秩序、重复 | 循环；团队 |

构图：层保持平行于屏幕；深度来自视差和纸色，不是透视。转场用纸动作（折、翻页、剥、飞纸、裁穿画面）；不要溶解。

## 5. 运动质量

- **人物以 12 fps 步进**（姿态采样在 `floor(t·12)/12`）；**镜头、光、天气、火焰和飞件以 24 fps on ones** 运动。
- 骨架在铆钉处钉住部件（颈、肩、肘、臀、膝、颚、尾）。硬姿态、微缓、1 帧过冲（"pop" = 1.15× 一步）。重量来自**尺寸和镜头震动**。
- **折叠**：翻片分成 ~16 条；每条用 cosθ 压缩、沿折叠方向放大 `1 + 0.28·height`（假透视）、站起来时变暗、超过 90° 用更亮的背面色、阴影增长、折后出现折痕。每折约半秒，各落一个拍点。
- **裁切**：图案通过剪刀路径上的圆遮罩揭示；外沿被裁后废料掉落一次；剪刀开合落在拍子细分上；碎屑飘出落地。
- **展开**：连续展开间隔几分之一秒，每片翻从折到平用缓出（"啪！"弹响），然后拍点上一个缩放弹和暖闪。

## 6. 声音调色板

- **音效跟随材质**：剪刀 = 金属剪切扫频（2.5–9 kHz）+ 短响 + 纤维裂声；折叠 = 沙沙 + 折痕拍；展开 = 尖锐弹响；重步 = *纸板*撞击不是肉；纸剥；粘贴 = 掌心拍；火柴划、呼；鞭炮 = 20–60 ms 间隔密击 + 低沉轰鸣。
- **乐器**：明亮中国室内乐团，不是钢琴弦乐也不是皮影的戏曲锣鼓：琵琶（长音颤音轮指）、古筝（分解和弦、滑音、颤音）、二胡（滑音）、笛子、笙或扬琴上色、木鱼、小大锣、手鼓。五声音阶。
- 选项：一剪 = 一拍细分；一升古筝滚奏、每出现一件一个音；手鼓心跳铺重量；一个大锣留给一个重音；完全沉默给屏息。

## 7. 原生技法

- **折—裁—展。** 折 2/4/8 次；一刀变多刀。展开落在强拍上。适合：一个老师、多学生；一个设计大量生产；一颗种子变成一片田。
- **镂空即光。** 剪纸从背光发深红光，每个镂空发光，图案投影到世界。适合：一个想法透过一个人；灯塔；故事关于家时夜里的窗。
- **对称复制。** 镜像母题剥开并倍增（团花 → 窗花 → 烟火）。适合：加盟；细胞分裂；一首歌在人群中传播。
- **碎屑有未来。** 裁切时掉落的碎片后来回来（作为雪、五彩纸屑、星星）。适合：回收；剩余时间；积少成多的小失败。
- **一切都是一张平纸。** 东西共享同样的裁法，所以山脊可以站起来变成生物，浪可以变成路。适合：变成地图的风景；其实是机器的工厂；拉远到做成的物件。
- **镜像对。** 两个从一张折叠纸裁出的人物。适合：双胞胎；伙伴关系；同一个人的前后。

## 8. 介质陷阱

- **红叠红**读成一团 → 不同纸族底、近远纸色、重叠用内嵌轮廓
- 通过 light map 调暗层也调暗覆盖它的 → 给层本身调色（multiply + 恢复 alpha）
- 扁平 cos 压缩的翻片读成滑动卡片而非折叠 → 条带假透视、站起来时变暗、显示背面色
- 裁切揭示显示未裁堆叠通过镂空 → 只在"未裁"遮罩内给堆叠厚度
- 剪刀指向后方 → 刀片轴沿行进方向、铆钉稍在裁切点后方
- 镜头间空白帧 → 出进纸动作重叠

## 10. 变化空间

三种远离示范的结构：
1. **十二刀的一年**：十二生肖或日历轮，每月一楔，旋转
2. **装配线**：一个产品用裁好的部件逐件组装，每个部件一个图案
3. **一封信**：折叠的讯息逐面板展开，每面板一个场景
