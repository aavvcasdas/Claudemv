# 皮影 · Shadow Puppetry

> 中国皮影戏：半透明染色皮偶，雕如蕾丝，压在棉布幕上，油灯从背后照亮。
> 参考语法：Lotte Reiniger《阿赫迈德王子历险记》(1926)（侧影表演、蕾丝般布景）；
> 陕西/华阴皮影（雕刻、色彩、锣鼓节奏）。勿复制特定历史皮偶、曲调或录音。

## 1. 本质与不是

一块白布幕；背后，用**半透明染色皮**切的扁平偶，被**油灯**照亮。色彩来自*透射光*：染料像彩色玻璃一样发光、镂空处最亮、重叠处变暗。偶用**可见线铆钉**连接关节，由**细杆**（颈部和手部）操纵，在幕布上显示为柔和的灰线。这是现场戏剧，不是定格动画：幕布**随灯闪烁**、偶**在手中颤抖**、松散部件**在铆钉上摆动**。

不是黑色剪影片（色彩是第二主角），不是剪纸（光*穿过*），不是彩色玻璃（没有铅线；碎片会移动和重叠），不是平面矢量裁切动画。

## 2. 材质与渲染

**渲染模型。** 每像素：`image = tonemap(lampLight × hideTransmission × clothTexture)`。
- `hideTransmission`：一个从**白色**开始的 2D canvas；每个部件用 `multiply` 绘制。镂空保持白色，重叠自动变暗。
- `lampLight`：每盏灯一个宽瓣 + 一个紧热点（~6:1），各自独立闪烁（~7 Hz 值噪声的几个百分点 + 更快的正弦）。暖光，绝不白色。
- `tonemap = 1 − exp(−hdr)`，曝光 ∝ `1/√(灯数)`：灯越多画面越漂白但仍可读。灯数是故事可以拧的旋钮。
- **布幕**：程序编织纹理（sin × sin + 噪声扭曲）、纤维斑点、低频密度斑块、暗边缘。后处理：暖调光晕、**暖暗角**（偏棕不偏灰）、轻微饱和度、柔 S 曲线、轻颗粒。

**皮与雕刻。** 将可平铺的皮质纹理（斑驳、纤维、斑点）乘入每个部件，用 `destination-in` 恢复 alpha 使镂空存活。**雕刻即密度**：留细条、挖掉大部分面积。镂空词汇：月牙行（鳞片、瓦片）、菱形格、铜钱孔（圆孔、方皮心）、云领与卷草、锥形缝（裂缝、雨、毛）、脊上分层、树冠叶孔。每个区域有暗色雕边（1.5–2.4 px）。

**人物是关节偶**：8–12 个部件，头 ~1.2× 真实大小配大头饰，袖子与躯干不同染料色，圆形关节瓣带铆钉（暗环 + 淡结），手臂由 2 骨 IK 从手部目标驱动，持有物件作为手线上的独立部件。正面人物有*镂空面部*（五官是围绕镂空的细条）；反面人物实心脸。

**布景**是雕好的组件放在大部分空白的发光布上：每元素一个蕾丝件，窄雕地面条，水面或天空用可提条。火、烟和流水是雕件在杆上，替换和摇动，不是粒子。

## 3. 色彩逻辑

- 所有色彩是**透射的**：染料过滤暖灯光，所以没有东西比灯更亮，每种色相都偏暖。
- 3–5 种饱和染料 + **原皮色**（中性）+ **墨**（轮廓、发、靴）。镂空是最亮的值。
- 重叠 = 暗：规划哪些部件交叉。
- 亮度来自灯的数量，不是调色。夜 = 少灯，不是加蓝。
- 示例组合：*宫廷*（朱红、赭、石绿）；*江上*（靛、翠、一赭）；*丰收*（焰橙、金、一绿）。

## 4. 运镜语法

| 运镜 | 表达 | 可服务于 |
|---|---|---|
| 观众席（全舞台，下方是人头） | "这是表演" | 传说；教训；框中记忆 |
| 从框架推进到幕布上 | 进入故事 | 故事中的故事；聚焦 |
| 横向平移宽幕 | 广度、地方展开 | 旅程；灾难的范围；行列 |
| 跟随一个偶，微放大 | 与一个角色同在 | 追逐；工作日 |
| ** percussion 点上急推几帧** | 鼓变成镜头 | 入场；定格姿势；揭示 |
| 沿移动部件甩镜 | 因到果 | 传来的消息；一击 |
| **锁定广角** | 变化的每一步都被看见 | 计数；重复；阶段 |
| 中近景，两个偶之间空布 | 距离、犹豫 | 选择；离别 |
| 特写雕刻细节 | 工艺即意义 | 誓言；工具；线索 |
| 从地面条到幕顶的仰摇 | 高度、等级 | 塔；天地 |
| 绕到背面（镜像） | 戏法被揭穿 | 幕后；谁在操纵 |
| 从幕布拉回到暗室 | 故事变成物件 | 余波；故事结束了 |

转场：灯熄灭、模糊前景柱擦、一件在光中提起、闪到暖白；绝不通用交叉溶解或数字擦除。

## 5. 运动质量

- **偶和镜头 24 fps 连续**；只有交换的特效件（火、水）以 12 fps 步进。
- 每个偶上都有**手颤**（几像素、~0.02 rad、低频），紧张时更强。
- 身体随主杆滑动；**腿、翎子、流苏是模拟的**（阻尼摆/弹簧链由身体加速度驱动，以固定速率预模拟以保证确定性）。
- 戏曲分句：碎步跑 → 跳 → 蹲 → **在锣鼓点上定格 ~1 秒（只有松散部分在颤）** → 转头。
- 脸从不变；态度 = 头角 + 身体倾斜（上 = 决心，下 = 悲伤）。
- **按上/提起**：到达时大且模糊地压到布上然后 ~0.5 秒变清晰；离开时变大、模糊、淡出 ~1 秒。

## 6. 声音调色板

- **锣鼓优先**（锣鼓经思维）：低桶鼓、硬高板鼓（木鱼）、铙钹、小锣升调（"台"）、大锣降调（"匡"）；还有竹板、拨浪鼓、三弦拨、安静时的竹笛。
- **弓弦和簧片**：明亮鼻音胡琴（类二胡：升高、鼻音共振峰、滑音和颤音用音高曲线重采样）、纯五声（*欢音*）或悲伤微分（*苦音*：升 4、降 7）；尖锐唢呐类簧片（双簧管 + 1.2–3 kHz 共振峰 + 饱和）最多一次。
- **沉默**：硬切整条床；沉默内最多一个声音。
- **音效跟随材质**：木块（醒木）、火柴划、灯"fwoomp"和"pfft"+ 嘶嘶声、杆敲布、提起时的干皮拍、皮脚步、皮和木道具的嘎吱声、皮击、布幕沙沙声。

## 7. 原生技法

- **光即世界。** 灯数驱动温度和色彩。适合：城市灯火夜间蔓延；发烧起伏；服务器逐一开启。
- **幕外 = 大且模糊。** 偶被拉向灯时变大变模糊。适合：传言滋长；记忆褪色；截止日期压到幕上然后变清晰。
- **到幕后去。** 灯、手、杆。适合：产品真实制造过程；谁控制市场；老师揭秘方法。
- **雕且透光。** 镂空发光、重叠变暗、开脸 vs 实脸。适合：系统的 X 光；寓言中的好坏角色；城市的层次。
- **手持。** 颤动和摆动部件。适合：紧张面试；走钢丝；学步。

## 8. 介质陷阱

- 扁平剪贴画感 → 皮质纹理、更密的镂空、更深的染料、雕边无处不在
- 侧面看不清人物 → 更大的头、更饱满的下半身、领片、对比袖子
- 放射形像锯条或花瓣 → 焰舌有胖底、圆腹和钩尖、交替卷曲
- 过曝时角变灰 → 暖暗角
- 淡色薄件消失 → 做深
- 镜像翻转时部件翻转 → x 缩放给 x、y 缩放给 y

## 9. 引擎映射（映射到 p5.brush / core.js）

| STYLE.md 概念 | 本项目实现 |
|---|---|
| 透射渲染 | WebGL 合成器层或 `paint()` multiply 模式 |
| 布幕纹理 | 程序编织噪声 + 纤维斑点 |
| 灯光场 | 径向渐变 + 值噪声闪烁 |
| 皮质纹理 | 可平铺程序纹理 |
| 关节偶 | 自制 2D 骨骼 + IK |
| 手颤 | `shakeXY()` 或低频 `wob()` |
| 按上/提起 | 缩放 + 模糊 + 淡入淡出 |
| 锣鼓节奏 | PROJECT.bpm 驱动，percussion hits 落 `pulse()` |

## 10. 变化空间

三种远离示范的结构：
1. **行列**：一个长平移；每个偶加一种染料直到布变成满街
2. **两个偶师**：敌对的手通过偶争论；幕后显示谁赢了
3. **工作坊**：一个偶在布上被雕、染、铆接，然后表演自己的制作
