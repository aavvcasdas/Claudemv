## 测量
- 容器 56.000 s；1920×1080；24 fps；原音轨 55.983 s、44.1 kHz 双声道 AAC（约 64 kb/s）。这只是上传片段，不代表完整歌曲。
- librosa 估计 143.55 BPM，首个检测拍点 0.093 s。可能有半拍/倍拍歧义；使用 report.json 的离散拍点比假定完全恒定 BPM 更准确。
- 能量抬升候选约 1.86 / 20.60 / 35.09 s；它们是算法候选，不等于乐理确认的副歌。
- ContentDetector(threshold=22) 返回空列表。说明未检出硬切，不说明原片没有叙事分镜；不采用“平均镜长 0 秒”。
- 未检测到明显反相抵消。noise_floor_db 是短窗能量低分位，不可理解为真实录音噪声测量。
