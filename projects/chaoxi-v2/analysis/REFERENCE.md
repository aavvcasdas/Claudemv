# 原片阅读与新版取舍

## 唯一输入
根目录 `潮汐.mp4`：56.000 s、1920×1080、24 fps。音轨约 55.983 s、双声道 HE-AACv2。
这不是参考仓库中的 31.84 秒《潮汐(Natural)》MP3；本项目不从文件名推断歌手或曲目。

## 自动量测与限制
`report.json` 来自已运行的 ReelMimic 分析工具。BPM 估计 143.55，首检测拍点 0.093 s，130 个拍点；可能有半拍/倍拍歧义，不作为乐理确认。
能量抬升候选 1.86 / 20.60 / 35.09 s 是算法候选，不能称为副歌或精确爆点。
硬切检测空结果只表示未检出超过阈值的突变，动画仍有构图和叙事段落。

## 逐段画面观察
见 reference-3s.jpg。孤独的圆形小世界 → 局部阴雨 → 遇见粉色伴侣、日出 → 大眼特写 → 背影看海 → 爱心 → 撑伞、一起发呆 → 天光打开 → 收集快乐与淘汰烦恼 → 依偎 → 烟花 → 单人卧水 → 两半星球的日夜时差 → 破心与眼泪 → 单人回到小星球。
**结尾并没有伴侣团聚。** 上一版的团聚是误读，本版恢复单人结局；收心到胸口是保留「忘了爱自己」语义的意象化表演，不声称原片逐像素有同样手势。

## 字幕与歌词处理
原片本身已有字幕，优先用本地 OCR 恢复，而不是拿另一首片段的 LRC 来套。
- `subtitles-ocr.json`：0.5 s 采样的原始结果，保留错误与候选。
- `assets/captions.json`：16 行，边缘附近每 0.125 s 再识别；采样量化半步约 0.0625 s，不是精确声学起唱误差保证。
- 从每个字幕框里的金/白像素比例提取原显示填色，12 Hz 采样、轻微平滑、单调约束。它是**行级显示进度**，不是每字音素边界。
- 对照原片字幕裁切图复核文字；「广袤」的「袤」被 OCR 漏掉或错识，已按原片 15 s 画面纠正。
- 新版保留原显示期间的短暂空隙，不用自动补词，不扩展到原片之外的歌曲部分。

## 重制边界
保留原音轨、56 秒总时长、人物关系、关键动作顺序和结尾。重新绘制青绿山水、纸纤维、朱砂/藕粉角色与金色伞，改小行星舞台与海岸的镜头语法。无原片视频帧作为新版背景；源片截帧仅用于分析证据。
